## C1 — Section Optimisation Loop

**Category:** ETABS Round-Trip | **Tests:** `<Var>` read + `<Script>` write + re-analyse

Reads concrete column DC ratios, identifies overstressed members (DCR &gt; 1.0),
upsizes their sections via a predefined upgrade map, and triggers re-analysis.

### What this tests

- `<Var>` pulling design results (DCRatio)
- `parse_table()` for design output tables
- Conditional write: only modify overstressed columns
- `sap.FrameObj.SetSection()` — changing section assignments
- `sap.Analyze.RunAnalysis()` — triggering re-analysis from script
- Full read-modify-reanalyse round-trip in a single connection

### Prerequisites

1. ETABS model with concrete columns designed (ACI 318 or similar)
2. Some columns should be overstressed (DCR &gt; 1.0) for the test to be meaningful
3. The upgrade_map section names must match your model's section names

### Expected behaviour

- `overstressed` — list of columns with DCR &gt; 1.0
- `upgraded` — count of successfully upsized columns
- `optimise_summary` — e.g. "Found 5 overstressed columns. Upgraded 3 sections. Re-analysis triggered."
- ETABS should show the re-analysis running after sync

### Caution

This script modifies section assignments and runs analysis. Use on a copy of your model.
