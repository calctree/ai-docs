## D1 — Beam Design Pipeline (ETABS to Excel)

**Category:** ETABS-to-Excel Pipeline | **Tests:** Two `<Connection>` nodes, `<Var>` + `<Input>` + `<Script>` on both

Reads beam design results from ETABS (reinforcement areas), then writes
them to a formatted Excel spreadsheet with headers and per-beam rows.

### What this tests

- **Two connection nodes on one page** — ETABS source + Excel destination
- `<Var>` pulling 5 columns from ETABS design summary
- `<Input>` pushing CalcTree variables to Excel cells
- `<Script>` on the Excel connection writing bulk data via COM
- `wb.Worksheets("...")` + `ws.Range(...).Value2` — Excel COM patterns
- Cross-connection data flow (ETABS script outputs used by Excel script)

### Prerequisites

1. ETABS model with concrete beam design completed
2. Excel workbook open with sheets named "Summary" and "Details"
3. Both ETABS and Excel connections must be established

### Expected behaviour

- ETABS connection populates `beam_design_data`, `beam_design_count`, `beam_design_summary`
- Excel connection pushes `beam_design_count` to Summary!B2 and `beam_design_summary` to Summary!B3
- Excel script writes headers + data rows to the Details sheet
- `excel_beam_summary` — e.g. "Wrote 42 beam records to Details sheet"
