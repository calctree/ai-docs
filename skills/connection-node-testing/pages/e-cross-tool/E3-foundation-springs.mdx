## E3 — SAFE Foundation Springs

**Category:** Cross-Tool Transfer | **Tests:** SAFE connection with `<Var>` read + `<Script>` write

Reads area objects from SAFE, assigns zone-based subgrade modulus (Ks) values
based on X-coordinate position, and writes spring stiffness back to each slab area.

### What this tests

- **SAFE software type** (not ETABS) — tests `software="safe"` adapter
- `<Var>` reading from SAFE database tables
- `parse_table()` working with SAFE (same CSI API pattern)
- `sap.AreaObj.SetSpring()` — writing spring assignments
- Coordinate-based zone classification logic
- Return value checking on per-element writes

### Prerequisites

1. SAFE foundation model open with area objects defined
2. Area spring assignments table exists
3. Model has area objects with centroid coordinates

### Expected behaviour

- `updated` — count of areas with successfully assigned springs
- `spring_summary` — e.g. "Updated subgrade modulus for 45 / 45 slab areas"
- Check SAFE: area spring assignments should show updated Ks values

### Caution

This modifies spring assignments in the SAFE model. Use on a copy.
