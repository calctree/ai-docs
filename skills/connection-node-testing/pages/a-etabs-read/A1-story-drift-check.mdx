## A1 — Story Drift Check

**Category:** ETABS Read-Only | **Tests:** `<Var>` pull + `<Script>` with `parse_table()`

Reads story drift ratios from ETABS for all seismic/wind combos and checks against
the ASCE 7 drift limit of 0.02 (h/50).

### What this tests

- Multiple `<Var>` tags pulling different columns from the same ETABS table
- `parse_table()` returning a list of dicts in the connection script
- Float parsing and conditional logic inside the script
- String output variables (`drift_summary`, `violation_details`)

### Prerequisites

1. Open an ETABS model with at least a few stories
2. Run all analysis cases (at least one lateral load case)
3. Ensure "Story Drifts" table is populated (check via ETABS Display &gt; Show Tables)

### Expected behaviour

After syncing, the connection script should populate:
- `drift_summary` — e.g. "Total rows: 48, Violations: 3"
- `violation_details` — either "All stories pass drift check" or a list of failing stories
