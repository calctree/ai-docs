## F1 — AASHTO Culvert Design Sheet

**Category:** Excel-Only | **Tests:** `<Var>` from two sheets + `<Script>` reading computed cells

Connects to an Excel-based AASHTO culvert design spreadsheet. Pulls geometry
inputs from the Input sheet and computed results from the Results sheet.

### What this tests

- Excel `<Var>` tags reading from **two different sheets** (Input + Results)
- 10 `<Var>` tags with specific cell addresses
- `<Script>` reading additional cells via COM (redundant read for validation)
- `wb.Worksheets("...")` — switching between sheets in script
- Mixed input/output cell reads (geometry inputs + computed design results)

### Prerequisites

1. An AASHTO culvert design spreadsheet with:
   - "Input" sheet with geometry in B3:B5 and material props in B8:B12
   - "Results" sheet with computed moments in D5:D6, shear in D10, status in D15
2. Formulas in the Results sheet should be live (not values-only)

### Expected behaviour

- `<Var>` values populate with the cell contents (numbers for dimensions, string for status)
- `culvert_summary` — e.g. "Culvert 3.0m x 2.0m, fill=1.5m. Status: PASS. M_top=45.2, M_bot=38.7"
